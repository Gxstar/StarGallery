# 2026-08-14 工作日志

## 底部导航栏文字显示不完整修复

现象：底部导航栏"照片""相册"文字显示不完整，用户判断是导航栏高度太低。

根因：`activity_main.xml` 与 `layout-land/activity_main.xml` 中 `BottomNavigationView` 固定高度 **72dp**，且 `labelVisibilityMode="labeled"`（常显文字）。Material3 的 BottomNavigationView 在 labeled 模式下标准高度是 **80dp**（`m3_bottom_nav_height`），72dp 比标准矮 8dp，item 内部为 label 预留的空间被压缩 → 文字行被裁剪。

改动：两个布局文件高度 72dp → **80dp**（编译通过）。

相关：悬浮胶囊样式（wrap_content 宽 + margin 32dp + 玻璃背景），`MainActivity.applyBottomNavWidth()` 控制宽度（≤480dp），`setupWindowInsets()` 控制底部 margin（18dp + 系统栏 inset），均不受影响。
