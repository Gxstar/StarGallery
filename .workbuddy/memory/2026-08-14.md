# 2026-08-14 工作日志

## 底部导航栏文字显示不完整修复

现象：底部导航栏"照片""相册"文字显示不完整，用户判断是导航栏高度太低。

根因：`activity_main.xml` 与 `layout-land/activity_main.xml` 中 `BottomNavigationView` 固定高度 **72dp**，且 `labelVisibilityMode="labeled"`（常显文字）。Material3 的 BottomNavigationView 在 labeled 模式下标准高度是 **80dp**（`m3_bottom_nav_height`），72dp 比标准矮 8dp，item 内部为 label 预留的空间被压缩 → 文字行被裁剪。

改动：两个布局文件高度 72dp → **80dp**（编译通过）。

相关：悬浮胶囊样式（wrap_content 宽 + margin 32dp + 玻璃背景），`MainActivity.applyBottomNavWidth()` 控制宽度（≤480dp），`setupWindowInsets()` 控制底部 margin（18dp + 系统栏 inset），均不受影响。

## 筛选功能重构（注册表驱动）

用户决策：完整重构而非删除；本轮只迁移现有相机品牌/型号/镜头三维，不新增光圈/快门等维度，不做省市县位置（locationAddress 几乎全 null，成本高）。

核心改动（编译 + 单测通过）：
- 新增 `filter/FilterState.kt`（单一不可变状态 + `FilterDimensions` 注册表 + `FilterOption`）、`filter/ActiveCondition.kt`（sealed 生效条件）。
- `PhotosViewModel` 重写为注册表驱动：`_filterState` 单一 StateFlow 替代 6 个逐维度 StateFlow + `recomputeEffective()` 级联写回；新增 `filterOptions`（faceted 内存统计）、`activeConditions`、`isFilterActive`、`dimensionFilterState`；`schedulePrune` 异步裁剪失效选择（替代级联反选 bug）。
- `FilterBottomSheet` 改为按 `FilterDimensions.ALL` 动态渲染维度行；`syncChipChecks()` 以 ViewModel 为唯一选中态真相源（修复 chip 视觉与实际脱钩 bug）。
- 首页新增生效条件 chip 条：`fragment_photos.xml` 与 `layout-land/fragment_photos.xml` 的 `AppBarLayout` 内各加 `chipBar`(HorizontalScrollView)+`chipGroupConditions`；`PhotosFragment.renderActiveConditionChips()` 据 `activeConditions` 渲染，逐条移除分派到 `setFavoritesOnly(false)` / `exitSearchMode()` / `clearDimension(id)` / `clearExcludedAlbums()`；维度 chip 点击主体打开筛选面板。
- 顶栏 `btnFilterExif` 高亮改为依据 `filterState.hasDimensionSelection`；`navigateToDetail` 从 `filterState.selectionOf(...)` 读取三维传给详情页。
- 清理 `PhotoDao` 废弃查询：`getCameraMakeCountsFlow`/`getCameraModelCountsFlow`/`getLensModelCountsFlow`/`getMakesForLenses`/`getModelsForLenses`/`getMakesForModels` 及 `ExifCount`（faceted 统计已迁至 ViewModel 内存计算）。

踩坑：横屏 `layout-land/fragment_photos.xml` 缺 chip bar id → ViewBinding 字段变 nullable；`FilterBottomSheet.buildDimensionRows` 局部 `val bottomMargin` 遮蔽了 `LinearLayout.LayoutParams.bottomMargin` 成员导致赋值报错。均已修复。

新增维度唯一改动点：`FilterDimensions.ALL` 注册表（连续量在 `valueOf` 直接分档成区间字符串避免 chip 爆炸）。
